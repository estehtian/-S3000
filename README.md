# S3000 — Somay & Esteh Tian

Landing page S3000 dengan arah visual futuristik modern: latar gelap, aksen cyan neon, highlight lime, tipografi tegas, serta komponen responsif untuk desktop dan ponsel.

## Struktur utama

- `index.html` — halaman utama dan showcase produk.
- `assets/css/` — sistem desain, responsivitas, dan animasi.
- `assets/js/` — navigasi mobile dan keranjang berbasis `localStorage`.
- `data/` — katalog produk dan konfigurasi identitas situs.
- `pages/` — halaman informasi dan kategori.

## Menjalankan

Buka `index.html` langsung atau jalankan server statis dari root repository, contohnya `python -m http.server 8000`. Gambar dan font mengambil aset eksternal sehingga memerlukan koneksi internet.

## Catatan

Keranjang versi ini tersimpan di browser pengunjung. Checkout, stok real-time, dan sinkronisasi pesanan membutuhkan integrasi backend yang dikonfigurasi secara terpisah.
