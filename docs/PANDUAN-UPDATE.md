# Panduan update katalog dan website

- Backup repository sebelum perubahan besar.
- Untuk data katalog bawaan, edit `assets/js/products.js` dan `data/products.json` agar tetap sejalan.
- Gambar lokal disimpan di `assets/images/somay/` atau `assets/images/esteh/`; path produk harus sesuai halaman yang memuat katalog.
- Jalankan server lokal dari root dan cek halaman sebelum commit.
- Admin demo menyimpan perubahan lokal saja. Untuk mengubah katalog publik, commit perubahan `products.js` ke repository.
- Jangan menaruh kredensial rahasia pada file HTML/JavaScript yang dipublikasikan.
