# Panduan publikasi GitHub Pages

1. Periksa `assets/js/config.js`, katalog di `assets/js/products.js`, nomor WhatsApp, harga, stok, alamat, dan jam operasional.
2. Pastikan `index.html` ada di root repository.
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**, pilih branch yang digunakan dan folder `/(root)`, lalu simpan.
5. Tunggu deployment selesai dan buka URL Pages.
6. Uji tautan navigasi, pencarian menu, keranjang, dan checkout pada perangkat seluler.

Admin katalog adalah demo localStorage dan tidak aman untuk operasional produksi.
