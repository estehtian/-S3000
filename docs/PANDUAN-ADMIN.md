# Panduan admin demo

Buka `admin/index.html` pada website. Form dapat menambah, mengedit, dan menghapus katalog di localStorage browser aktif. Tombol ekspor/impor membantu memindahkan data manual.

**Penting:** data tidak tersinkron ke browser pengunjung atau perangkat lain. Halaman tidak memiliki login dan bukan sistem manajemen produksi. Jangan simpan data pelanggan, pesanan nyata, atau rahasia di sini. Perubahan data browser tidak mengganti file `assets/js/products.js` di repository.
